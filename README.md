# Thulir Infra

Official website for **Thulir Infra** — Civil engineering, architectural planning, residential and commercial construction, DTCP and statutory plan approvals, Project Management Consultancy (PMC), and bank estimation services across Madurai, Virudhunagar, Namakkal, Trichy, Salem, and surrounding regions in Tamil Nadu.

## Features & Services

- **Residential Construction**: Packages from standard to luxury (Premium ₹2,400/sq.ft, Luxury ₹2,450/sq.ft, Elite ₹2,600/sq.ft).
- **Commercial Construction**: Functional commercial builds starting from ₹1,600/sq.ft.
- **Architectural & Structural Planning**: Comprehensive layouts adhering to statutory norms.
- **Approvals & Liaison**: DTCP and local body plan approvals.
- **Project Management Consultancy (PMC)**: Quality control, scheduling, and budget supervision.
- **Materials Supply**: Quality 20mm & 40mm aggregate, chips, M-Sand, P-Sand, river sand, and cement.
- **Banking Assistance**: Bank estimation and loan documentation guidance.

## Tech Stack

- **Framework**: TanStack Start (SSR) with React 19
- **Routing**: TanStack Router (File-based)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Bundler & Server**: Vite & Nitro
- **Testing**: Vitest & Testing Library

## Getting Started

### Prerequisites

- Node.js (>= 20) or Bun (>= 1.2)

### Installation

```sh
bun install
# or
npm install
```

### Development

```sh
bun run dev
# or
npm run dev
```

### Production Build

```sh
bun run build
# or
npm run build
```

### Testing

```sh
bun run test
# or
npm test
```
